API Reference¶

This section documents the most frequently used modules. All classes operate on numpy arrays or pandas DataFrame inputs and run TensorFlow under the hood.

get_stimulus_pdf(data, stimulus_range, parameters=None, weights=None, omega=None, dof=None, normalize=True, include_multidimensional_stimulus_index=False, noise_model=None, temperature=None)¶

Evaluate posterior over stimuli for each time point given data.

Parameters:

  • data (DataFrame or array (n_timepoints, n_voxels))

  • stimulus_range (array (n_stimuli,) or (n_stimuli, n_dims)) – Grid of candidate stimuli (flat prior over the grid).

  • omega (array, float, optional) – Dense noise covariance and Student-t degrees of freedom (dof=None = Gaussian), e.g. from ResidualFitter.fit. Ignored when noise_model is given.

  • dof (array, float, optional) – Dense noise covariance and Student-t degrees of freedom (dof=None = Gaussian), e.g. from ResidualFitter.fit. Ignored when noise_model is given.

  • noise_model (braincoder.noise.LowRankNoise, optional) – Factored noise model (low-rank + diagonal Ω, Gaussian or Student-t). The likelihood is evaluated with the Woodbury identity (no dense V × V matrix). Its temperature is applied unless temperature is passed explicitly.

  • temperature (float, optional) – Likelihood temperature T: posterior ∝ likelihood^(1/T). Default None = 1 (or the noise model’s own temperature). np.inf gives a flat posterior.

class braincoder.optimize.ParameterFitter(model, data, paradigm, memory_limit=666666666, log_dir=False)¶

Bases: object

Iterative optimizer that estimates model parameters for each voxel.

Single trainable (n_voxels, n_pars) keras Variable; only the masked positions (meaningful voxels × non-fixed params) receive gradients. Shared parameters are realized by a smaller Variable that’s broadcast back across voxels via a selector matrix.

Parameters:

  • model (EncodingModel)

  • data (pd.DataFrame) – Timeseries, shape (n_timepoints, n_voxels).

  • paradigm (array-like) – Stimulus paradigm; passed through model.get_paradigm.

  • memory_limit (int) – Soft budget for the grid-fit chunk size.

  • log_dir (str | None | False) – TensorBoard log dir. False (default) disables logging.

fit(max_n_iterations=1000, min_n_iterations=100, init_pars=None, confounds=None, optimizer=None, fixed_pars=None, shared_pars=None, noise_model='ssq', store_intermediate_parameters=False, r2_atol=1e-06, lag=100, learning_rate=0.01, progressbar=True, **kwargs)¶

Estimate per-voxel parameters by iterative optimization.

Parameters:

  • noise_model ({‘ssq’, ‘gaussian’}, default 'ssq') – Loss function. 'ssq' minimizes the unweighted sum-of-squared-residuals (MLE under homoscedastic Gaussian noise). 'gaussian' minimizes a per-voxel Gaussian negative log-likelihood with a free per-voxel σ²ᵥ; the θ-gradient is auto-rescaled by per-voxel noise, which under a shared Adam optimizer gives every voxel comparable per-iteration progress. Same fixed points as 'ssq', but much faster convergence in practice on real fMRI (heteroskedastic noise). When set, self.estimated_sigma2 holds the fitted per-voxel σ² after fit() returns.

  • fixed_pars (list[str] | None) – Parameter names to hold at their init value (fixed_pars) or to tie to a single shared value across voxels (shared_pars).

  • shared_pars (list[str] | None) – Parameter names to hold at their init value (fixed_pars) or to tie to a single shared value across voxels (shared_pars).

  • r2_atol (float, int, int) – Early-stop: stop when R² has improved by less than r2_atol over the last lag steps, after min_n_iterations.

  • lag (float, int, int) – Early-stop: stop when R² has improved by less than r2_atol over the last lag steps, after min_n_iterations.

  • min_n_iterations (float, int, int) – Early-stop: stop when R² has improved by less than r2_atol over the last lag steps, after min_n_iterations.

  • **kwargs – Forwarded to keras.optimizers.Adam when optimizer is None.

Returns:

Per-voxel parameter estimates, indexed by voxel.

Return type:

pd.DataFrame

class braincoder.optimize.ResidualFitter(model, data, paradigm=None, parameters=None, weights=None, lambd=0.0)¶

Bases: object

Fit a parametric noise covariance Ω (and Student-t ν) to residuals.

Ω = ρ ττᵀ + (1 − ρ) diag(τ²) + σ² WWᵀ (optionally mixed with the sample covariance via lambd).

Warning

Ω has a single shared factor. On real single-trial fMRI betas the residuals typically need tens of factors, and this Ω underestimates held-out noise (held-out Mahalanobis distances ~4× too large on 7T data), giving overconfident decoding posteriors. lambd > 0 is unsafe when n_voxels > n_trials (rank-deficient sample covariance). The pseudo-WWᵀ from init_pseudoWWT is uncentred. For calibrated decoding see braincoder.noise.LowRankNoise and the “Noise models for decoding” docs page.

fit(init_rho=0.1, init_tau=None, init_dof=1.0, init_sigma2=0.001, D=None, max_n_iterations=1000, resid_dist='gauss', min_n_iterations=100, method='gauss', residuals=None, normalize_WWT=True, use_wwt=True, learning_rate=0.02, rtol=1e-06, lag=100, init_alpha=0.99, init_beta=0.0, spherical=False, progressbar=True, max_consecutive_failures=50)¶

use_wwt (default True): include the σ² · WᵀW term in Ω. When False, Ω is built without the tuning-similarity contribution — useful for testing whether WᵀW is doing real spatial-noise modeling or just creating signal-correlation structure that interacts with regularized encoding fits. σ² stays in the trainable set but has zero effect on Ω (gradient → 0; Adam leaves it inert).

Failure handling: a step whose cost or gradients are non-finite, or which raises a numerical error (e.g. a Cholesky failure), is rolled back to the best values so far and the learning rate is reduced by 10%. max_consecutive_failures (default 50) such steps in a row raise RuntimeError. Programming errors (TypeError – including JAX tracer-conversion errors – AttributeError, NameError, …) are re-raised immediately. If no step ever produces a finite cost the fit raises instead of returning an unfitted Ω. The number of rolled-back steps is stored in self.n_failed_steps.

Fit a low-rank noise model; choose k and T by nested CV.

Parameters:

  • model (EncodingModel)

  • data (DataFrame (n_trials, V)) – Training data only (the test data must never be passed here).

  • paradigm (DataFrame or array (n_trials, n_stim_dims)) – True stimulus of every training trial.

  • parameters (DataFrame, optional) – Encoding parameters (default model.parameters).

  • stimulus_range (array (n_stimuli,) or (n_stimuli, n_dims)) – The decoding grid — use the same grid as for get_stimulus_pdf. Required when k or temperature is chosen by CV. True training stimuli are matched to the nearest grid point.

  • groups (array (n_trials,), optional) – Group label per training trial (e.g. run). Inner CV leaves one group out at a time. Strongly recommended: trials within a run share noise. Without it, n_folds contiguous blocks are used.

  • k ('cv' or int)

  • temperature (‘cv’ or float (np.inf = flat posterior))

  • dof ('fit', None or float) – Student-t ν by ML (‘fit’), Gaussian (None) or fixed.

  • k_grid (sequences) – Candidates for CV. k values ≥ the number of inner-training trials or voxels are dropped.

  • temperature_grid (sequences) – Candidates for CV. k values ≥ the number of inner-training trials or voxels are dropped.

  • inner_parameters (None, dict or callable) –

    Encoding parameters used inside inner fold g.

    • None (default): parameters are held fixed. The inner held-out trials were then part of the data the encoding model was fitted on, so their predictions are slightly optimistic and the chosen T is, if anything, too small (posteriors a bit too sharp).

    • dict {group: parameters}: precomputed parameters that did not see group g (e.g. existing leave-one-run-out fits).

    • callable f(train_data, train_paradigm, group) -> parameters: refit the encoding model on the inner-training trials.

    In fold g, Ω is fitted on the residuals of the inner-training trials under these parameters, and the held-out trials are decoded with them.

  • psi_floor (float) – Floor on the diagonal uniquenesses (correlation scale).

Returns:

Fitted on all training trials with the chosen k; carries the chosen temperature, cv_scores_ and cv_info_.

Return type:

LowRankNoise

Notes

The CV objective is the summed held-out log posterior probability of the true stimulus on the grid, log p_T(s* | y), under a flat prior over the grid. This is the decoding objective; it is not the covariance likelihood (which prefers ever larger k on fMRI data while decoding gets worse). For every inner fold and every k, Ω(k) and ν are refitted on the inner-training residuals; all T are evaluated on the same likelihood table at no extra cost.

classmethod from_residuals(residuals, k=40, dof='fit', psi_floor=0.02, temperature=1.0, _svd=None)¶

Fit Ω (and ν) to residuals for a fixed rank k.

Principal-factor model of the residual correlation (one closed-form step, no iteration): F = first k eigenvectors × √eigenvalues, Ψ = 1 − diag(F Fᵀ), floored at psi_floor; then an overall scale c and ν are fitted by maximum likelihood (Student-t; dof=None for Gaussian, a number to fix ν).

Parameters:

  • residuals (DataFrame or array (n_trials, V))

  • k (int) – Number of factors (capped at min(n_trials, V) − 1).

grid_log_likelihood(data, predictions)¶

Log-likelihood table (n_trials, n_stimuli).

data: (n_trials, V); predictions: (n_stimuli, V), the model prediction for every candidate stimulus. Computed as d²(t, s) = q(y_t) + q(μ_s) − 2⟨y_t, μ_s⟩ with all terms in factored form — one (n_trials × V) · (V × n_stimuli) product, no dense Ω and no (n_stimuli × n_trials × V) residual tensor. float64 numpy.

Calibration diagnostics¶

Calibration metrics for grid posteriors (e.g. from get_stimulus_pdf).

All functions take a posterior DataFrame — rows = trials, columns = grid stimuli — and the true stimulus of every trial. Rows are renormalised to sum to one (discrete masses over the grid), so both the trapezoid-normalised 1-D densities and the max-normalised multi-dimensional output of get_stimulus_pdf can be passed directly.

A calibrated posterior gives

  • randomised PIT values ~ Uniform(0, 1) (1-D only; SD ≈ 0.289, slightly less on a coarse discrete grid), U-shaped = overconfident, ∩-shaped = underconfident;

  • randomised HPD levels of the truth ~ Uniform(0, 1), i.e. the q-HDI contains the truth on a fraction q of trials (any dimensionality);

  • a log score that is not below that of a flat posterior.

Randomisation (a uniform draw within the probability mass of the true grid cell) makes the statistics exactly uniform for a calibrated discrete posterior instead of biased by ties and grid coarseness.

braincoder.utils.calibration.calibration_summary(pdf, true_stimulus, grid=None, levels=(0.5, 0.95), rng=0)¶

One-row summary: log score vs uniform, HDI coverage, PIT SD (1-D), posterior mean r / MAE / posterior SD (1-D).

braincoder.utils.calibration.hdi_coverage(pdf, true_stimulus, levels=(0.5, 0.95), grid=None, rng=0)¶

Fraction of trials whose q-HDI contains the truth, for each q.

braincoder.utils.calibration.hpd_level(pdf, true_stimulus, grid=None, rng=0)¶

Randomised level of the smallest HDI that contains the truth.

h = P(p(s) > p(s*)) + U · P(p(s) = p(s*)). The q-HDI covers the truth iff h < q. Works for any dimensionality.

braincoder.utils.calibration.log_score(pdf, true_stimulus, grid=None, relative_to_uniform=True)¶

Per-trial log posterior mass of the true grid cell.

With relative_to_uniform (default) log(1/n_stimuli) is subtracted, so 0 = as good as a flat posterior and > 0 = informative and calibrated enough to beat it.

braincoder.utils.calibration.marginalize(pdf, dimension, grid=None)¶

Marginal posterior over one stimulus dimension (int or level name).

braincoder.utils.calibration.pit(pdf, true_stimulus, grid=None, rng=0)¶

Randomised probability integral transform (1-D posteriors).

F(s* − 1) + U · p(s*), U ~ U(0, 1). For a multi-dimensional posterior, first marginalize() it.
